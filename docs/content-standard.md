# 직업·학과 콘텐츠 기준

"마이로드 심화" 직업·학과 페이지(`src/data/jobs.ts`·`majors.ts`에 넣는 것)는 아래 항목을 모두 채운다. 지금 있는 직업 51개·학과 56개와, 커리어넷 직업 가운데 심화로 옮기는 직업·학과 모두 같은 기준을 쓴다.

그 밖의 커리어넷 직업·학과(직업 505·학과 447, 2026-11-23)는 "커리어넷 공식 정보" 페이지로 자동 생성된다(`/jobs/cn/[번호]`, `/majors/cn/[번호]`). 이 페이지는 커리어넷 원문을 그대로 보여 주고 "마이로드 심화 내용은 아직 없어요" 안내를 붙인다. 학생이 많이 찾는 직업은 위 기준을 채워 심화로 옮긴다.
형식: `src/data/deep/types.ts`. 데이터 위치: `src/data/deep/*.ts`. `npm run validate`가 빠진 항목과 최소 개수를 검사한다.

## 공통 원칙
- 중·고등학생 눈높이의 존댓말("~해요"), 한 문장은 짧게.
- **지어내지 않는다.** 임금·취업률·합격선 같은 숫자, 실존 인물 인용, 특정 기관의 확인되지 않은 사실은 쓰지 않는다. 숫자가 필요하면 커리어넷·고용24 공식 자료 링크로 안내.
- 일반적인 경로를 쓰되 다른 경로가 있으면 함께 쓴다(예: 특성화고·전문대 경로).
- 성별·외모 고정관념 표현을 쓰지 않는다.
- 경남 정보는 확인된 것만(`src/data/gn.ts`의 산업·학교 연결).

## 직업 페이지
| 항목 | 기준 | 커리어넷 연동 시 |
|---|---|---|
| 한 줄 요약(`summary`) | 1문장 | 직업 요약 |
| 소개(`intro`) | 2~3문장: 무엇을, 왜 중요한지 | 직업 개요를 쉬운 말로 다시 씀 |
| 하는 일(`work`) | 5~7개, 구체적 동작 | 하는 일 목록 |
| 하루 흐름(`day`) | 4단계, "예시"로 표시 | 직접 작성 |
| 필요한 지식·능력(`skills`) | 4~5개 + 왜 필요한지 | 능력·지식 항목 참고 |
| 흥미 유형·가치관 | RIASEC 1~3개, 가치 2~3개 | 흥미·가치관 항목 |
| 근무 환경(`env`) | 장소·근무 형태·함께 일하는 사람 | 업무 환경 |
| 학력·경로(`edu`) + 되는 방법(`prepare`) | 1~2문장 + 단계 3개 | 준비 방법·관련 학과 |
| 관련 자격(`certs`) | 국가(전문)자격 공식 명칭 | 관련 자격 |
| 경력이 쌓이면(`growth`) | 1~2문장 | 직접 작성 |
| 앞으로의 전망(`outlook`) + 기술 변화(`future`) | 정성적 설명 | 직업 전망 요약(숫자는 링크) |
| 고등학생 활동(`hs`) / 중학생 활동(`msActions`) | 3~4개 / 3개 | 직접 작성 |
| 자주 묻는 질문(`faq`) | 2~3개 | 직접 작성 |
| 관련 학과·고교 과목·고교 유형·영상 | 연결 데이터 | 관련 학과, 영상 자동 매칭 |

## 학과 페이지
| 항목 | 기준 | 커리어넷 연동 시 |
|---|---|---|
| 한 줄 설명(`desc`) | 1문장 | 학과 개요 요약 |
| 소개(`intro`) | 2~3문장 | 학과 개요를 쉬운 말로 |
| 이런 질문을 탐구해요(`questions`) | 3개 | 직접 작성 |
| 세부 전공(`tracks`) | 3~5개 + 설명 | 세부 관련 학과 참고 |
| 학년별 흐름(`years`) | 4단계 | 주요 교과목을 학년 흐름으로 |
| 대학에서 배우는 과목(`univ`) | 3~6개 | 주요 교과목 |
| 길러지는 능력(`skills`) / 적성(`aptitude`) | 3~4개 / 2~3개 | 흥미·적성 |
| 헷갈리는 학과와 차이(`compare`) | 1~2개 | 직접 작성 |
| 고교 핵심·권장 과목 | 공식 권장과목이 없으면 "일반적 안내" 표시 | 직접 작성 |
| 고교 탐구 주제(`hs`) / 활동(`activities`) | 3개 / 3개 | 직접 작성 |
| 졸업 후(`after`) + 진출 분야·관련 직업 | 2문장 + 목록 | 진출 분야·관련 직업 |
| 관련 자격 | 공식 명칭 | 관련 자격 |
| 자주 묻는 질문(`faq`) | 2개 | 직접 작성 |
| 개설 대학(경남 먼저)·영상 | 연결 데이터 | 개설 대학 |

## 커리어넷 연동 때 할 일
1. 커리어넷에서 받은 직업·학과를 위 표의 항목에 넣고, 비어 있는 항목(하루 흐름, 질문, 비교, FAQ 등)은 기준에 맞춰 작성한다.
2. 출처(커리어넷)를 페이지에 표시하고, 원문을 그대로 길게 옮기지 않고 학생 눈높이로 다시 쓴다.
3. `npm run validate`로 빠진 항목이 없는지 확인한 뒤 공개한다.
