# 기능 대조표: 대구 플랫폼(dgcareer) ↔ 마이로드 경남

원본 기능 목록은 `dgcareer-inventory.md`를 기준으로 한다. 상태: ● 동등 이상 · ◐ 일부(사유 기재) · ○ 미구현.

| 대구 플랫폼 기능 | 마이로드 경남 | 상태 | 비고 |
|---|---|---|---|
| E-Book 진로·학업설계 가이드 | `/guide` 단계별 가이드북 + 고교학점제 안내 | ● | 중·고 학교급별 흐름 |
| 고교 선택 가이드 | `/highschool` 유형별 심층 분석, 경남 전형 회차 필터, 3단계 로드맵, D-day, 일정 .ics | ● | 경남 고입포털 기준 |
| 학교 찾기·통학 | `/schools` 지도(경남 고교 203·중학교 270), 주소 검색, 통학 시간 추정 | ● | |
| 과목 선택 백과 | `/subjects` 2022 개정 290과목, 목록·계열 트리·내신·192학점·고교학점제 탭 | ● | hscredit.kr 공식 과목 목록 |
| 고교별 학점 설계 시뮬레이터 | `/credits`, `/credits/school` 편제표 편집기, 192학점 진단·자동 채우기, 공유 코드 | ● | 계열 9개 모두 경고 없이 192 자동 완성 |
| 전국 대학 학과·권장이수과목 | `/majors` 학과 가이드 56개 + 전국 학과 탐색(444개 대학·16,257개 학과, 경남 먼저) | ◐ | 대학별 권장과목은 PDF로만 공개되어 데이터화 불가 → 대학 누리집 링크 |
| 직업 백과 + 영상 | `/jobs` 51개 직업(경남 산업 직업 10개 포함), 적성·되는 방법·일하는 곳·자격·전망, 직업인 영상과 채널 검색 | ◐ | 커리어넷 500여 직업 전체는 API 키 필요 |
| 진로검사·상담 | `/tests` 검사 20종, `/discover` 흥미 탐색, 상담 창구 3곳 | ● | |
| 진로체험·진로자료 | `/resources` 꿈길·진로체험지원센터 18곳, `/future` 신산업 퀴즈·친화도, `/transition` 고3 10차시 | ● | |
| 디지털 진로 포트폴리오(활동·192 로드맵·독서) | `/portfolio` 중학 4단계·고교 5단계 활동, 로드맵에 학점 설계 내장, 독서 기록 | ● | 기기 안에만 저장 |
| 2028 대입정보 | `/admission` 수능 시간표, 대학별 2028 전형 기본계획(233개 대학 PDF 링크), 내신 시뮬레이터, 계산기 | ◐ | 전국 수시·정시 결과 원자료는 공개 데이터 없음 |
| 통합 검색 | 헤더 실시간 검색, `/search` | ● | |
| 리포트·공유 | `/report` 인쇄·공유 링크 | ● | |
| (대구에 없음) | 경남 산업 진로 지도 `/industry`, 학년별 계획 `/plan`, 진로 경로 `/path` | 추가 | |

## 키가 있어야 더 확장되는 항목

| 항목 | 필요한 것 | 발급처 |
|---|---|---|
| 직업 500여 개·학과 상세·직업인 인터뷰 | 커리어넷 Open API 인증키 | career.go.kr → 오픈API 센터 → 인증키 신청 |
| 학교 급식·시간표 상세 | NEIS 교육정보 개방포털 인증키 | open.neis.go.kr → 인증키 신청 |
| 직업별 영상 자동 연결 | YouTube Data API 키(선택) | Google Cloud Console → API 사용 설정 |
| 공공데이터 자동 갱신 | 공공데이터포털 serviceKey(선택) | data.go.kr → 활용 신청 |

키는 저장소에 넣지 않고 GitHub Secrets에 등록한 뒤 빌드 단계에서 읽는다.
