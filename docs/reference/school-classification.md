# 경남 고교 분류 점검 (2026-11-22)

## 방법
경남 고교 203곳 모두를 세 자료와 대조했다.
- 경상남도교육청 고등학교 입학포털 고교현황(`scripts/raw/gne_schools.json`): 전형 구분 코드
- 나이스 학교기본정보(학교명 개별 조회): 고등학교구분(일반고·자율고·특목고·특성화고), 특수목적고 계열, 일반/전문계
- 경상남도교육청 보도자료(2025-08-28): 자율형 공립고 2.0 지정 학교

## 매년
