# 심화 직업·학과 본문 사실 점검 (2026-11-24)

대상: `src/data/gen/{jobs,jobs-deep,majors,majors-deep}.json` (직업 506·학과 447). 규칙: CLAUDE.md 결정 사항 1·5번(지어내지 않기).

## 방법
1. 표본: 분야(직업 12개)·계열(학과 9개)별 비례 층화 추출, 시드 20261124 (mulberry32). 직업 59개, 학과 51개. 표본 id는 `scripts`에 두지 않고 이 문서의 방법으로 재현한다(분야별 정렬 후 시드 셔플, 분야마다 최소 2개).
2. 표본 항목은 사람이 읽고 검증 가능한 주장(자격·면허 이름, 학력·경로, 기관 이름, 제도, 수치, 과목·학과 연결)을 `src/data/careernet/job-detail.json`·`major-detail.json`(커리어넷 원문)과 대조했다.
3. 같은 검사를 표본이 아니라 전체(직업 506·학과 447)에 자동으로 돌렸다: 자격 이름(기사·산업기사·기능사·기술사·기능장) 근거 대조, 기관 이름, 숫자·연봉·취업률·%·연도 문장, 과장 표현, 낡은 제도·기관 이름, 학과·과목 이름(`npm run validate`).

## 결과 요약
- 본문은 커리어넷 원문을 쉬운 말로 다시 쓴 것이어서 지어낸 사실은 찾지 못했다.
  - 자격 이름: 전체에서 커리어넷에 없는 이름은 "한식·양식·일식조리기능사"처럼 묶어 쓴 표기 20건뿐(실제 종목은 모두 존재).
  - 연봉·취업률·%·억·만원 같은 수치: 0건. 숫자는 학년·급수(1~3급)·수업 연한(로스쿨 3년, 치전원 4년)·보수교육 4시간·운전경력 1년 같은 제도 값뿐이고, 모두 커리어넷 원문에 있다.
  - 커리어넷에 없는 기관 이름: 일반 명사(책임연구원, 문화센터 등) 31개뿐, 가공의 기관 없음.
  - 직업별 관련 학과(jobs.json `majors`): 1,677건 전부 커리어넷에 있음. 학과 `univ` 과목: 2,265건 중 11건(0.5%)만 원문에 없음(교양 기초 과목명 등 무해).
  - 과목 이름: `npm run validate`가 모두 통과(과목 290개 기준).
- 문제는 **커리어넷 원문의 낡은 이름이 그대로 옮겨진 것**이 전부였다.

## 아직 확신 못 한 것 (고치지 않음)
- "병원행정사"(학과 8곳·직업 2곳): 커리어넷은 관련 자격으로 적지만 국가자격이 아닌 민간 자격일 가능성이 있다. 확인 필요.
- "건강보험사"(학과 3곳): 공식 국가자격 이름으로 확인하지 못했다.
- 환경부(학과 2곳): 정부 조직 개편으로 부처 이름이 바뀌었을 수 있다. 공식 확인 전에는 두었다.
- 학과 FAQ "문과·이과 중 어디가 유리한가요?"(약 20곳): 2022 개정에서 문·이과 구분이 없어졌는데도 일상어로 쓴다. 답은 "둘 다 괜찮아요" 식이라 사실 오류는 아니나 문구 정리를 권한다.
- 커리어넷이 갱신되면(주간 동기화) 낡은 이름이 `src/data/careernet`에는 남는다. 화면은 원문 그대로라 마찬가지로 낡은 이름이 보일 수 있다(이 점검 범위 밖).
- 지역 사례(경남 공룡 발자국 화석, cn-30·537)는 일반 상식 수준에서 맞지만 출처를 따로 확인하지 않았다.
