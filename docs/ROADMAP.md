## 다음 우선순위
1. **경남 학교 편제표 확보** — 학교 누리집·고교학점제 누리집에 공개된 편제표를 학교 측 동의 하에 등록해 예시 편제표 대신 실제 편제표 제공. (편제표 형식: `src/data/curriculum.ts`의 `SchoolCurriculum`)
2. **커리어넷 Open API 연동** — 직업·학과 정보를 공식 데이터로 확장(키 발급 필요). 정적 사이트이므로 빌드 시 수집해 JSON으로 저장하는 스크립트 방식 권장.
3. **선택 기능: 로그인·기기 간 동기화** — Firebase Authentication + Firestore. 미성년자 개인정보 처리 방침, 보호자 동의 절차를 먼저 정할 것. 기본은 지금처럼 로그인 없이 사용.
4. **교사용 화면** — 학생이 공유 링크/파일로 제출한 리포트·설계서를 모아 보는 기능(동기화 기능과 함께 검토).
5. **대학별 권장과목** — 대학이 공개한 자료를 출처와 함께 정리(현재는 어디가 링크로 안내).
