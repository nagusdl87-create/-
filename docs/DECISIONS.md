## 대기 중
- **D3. 개인정보 처리 방침 초안을 확인해 주세요** (`docs/privacy-draft.md`). 특히 3항 만 14세 미만 처리 방식을 골라 주세요.
  - A. 만 14세 미만은 로그인 제한, 기기 저장으로 모든 기능 이용 (추천: 보호자 동의 확인 절차·기록 보관 부담 없음. 중1 대부분은 로그인 없이 사용)
  - B. 만 14세 미만도 보호자 동의 절차를 거쳐 로그인 허용 (구현·운영 부담 큼)
  - 그 밖에 고칠 문장이 있으면 함께 알려 주세요. 확인되면 `/privacy`로 게시하고 로그인 기능을 공개해요.
