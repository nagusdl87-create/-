# 결정 요청

자동 작업 에이전트가 사용자 결정이 필요한 항목을 여기에 적는다. 답은 Claude 대화창에 "D1은 A로" 처럼 남기면 된다.

## 대기 중
- **D1. 로그인·기기 간 동기화를 넣을까요?** 학생이 학교·집 컴퓨터에서 같은 기록을 보려면 로그인이 필요해요. 미성년자 개인정보 처리 방침과 보호자 동의 안내가 함께 필요해요.
  - A. 넣지 않음, 지금처럼 기기 저장 + 공유 링크/파일 (추천: 개인정보 부담 없음)
  - B. 선택 기능으로 구글 로그인 추가 (처리 방침 초안은 에이전트가 작성, 게시 전 확인)
- **D2. 다문화 학생·보호자를 위한 쉬운 한국어/영어 안내를 만들까요?**
  - A. 주요 페이지(홈·고입 일정·고교 유형)만 영어 요약 추가 (추천)
  - B. 하지 않음

## 결정됨
- (2026-11-22) 자동 작업: 하루 2회 실행, 검사(검증·빌드·브라우저 테스트) 통과 시 자동 배포.
