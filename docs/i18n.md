# 영어 버전 만들기 규칙 (한국어/English)

결정: 모든 내용 완전 영어(2026-11-22). 구조: `src/lib/i18n.tsx`.

## 화면 문구
- 컴포넌트에서 `const t = useT();` 후 `t("한국어 문구")`. **키는 화면에 보이는 한국어 문구 그대로**, 영어는 `src/i18n/en/<영역>.ts`에 `"한국어": "English"`로 넣는다.
- 변수는 자리표시: `t("{n}개 직업", { n: jobs.length })` → 사전 `"{n}개 직업": "{n} jobs"`. 문장을 + 로 이어 붙이지 않는다(어순이 다름).
- 속성도 번역: `aria-label`, `placeholder`, `title`, 페이지 `<title>`/설명(서버 metadata는 한국어 유지, 화면 제목은 t).
- 한국어로 두는 고유명사(학교·기관 이름, 과목 정식명과 함께 쓰는 원어)는 감싼 요소에 `translate="no"` 또는 `data-keep-ko`를 붙인다(검사에서 제외). 필요하면 영어 설명을 옆에 둔다. 예: `<span data-keep-ko>삼천포여자중학교</span>`.

## 자료(직업·학과·과목·학교 유형 등)
- 영어 자료는 `src/i18n/data/<이름>.en.ts`에 id를 키로 같은 모양으로 만든다(예: `JOBS_EN[id] = { name, summary, tasks, … }`).
- 화면에서는 `const en = useEnData(() => import("@/i18n/data/jobs.en"), "jobs")`로 영어 모드일 때만 불러와 `en?.JOBS_EN[id]?.name ?? job.name`처럼 쓴다. 한국어 사용자는 영어 자료를 내려받지 않는다.
- 서버 `page.tsx`가 골라 넘기는 상세 자료(직업·학과 상세)는 영어판도 같은 방식으로 골라 넘긴다.

## 번역 원칙
- 쉬운 영어(CEFR B1~B2), 학생·보호자 대상. 한국 교육 제도 용어는 영어 + 괄호에 한국어(예: early admission round (전기)). 처음 나올 때만 괄호.
- 내용을 늘리거나 줄이지 않는다. 숫자·날짜·이름은 그대로. 사실을 바꾸지 않는다.
- 학점(credit), 내신(school grades), 수능(CSAT), 고교학점제(high school credit system), 특성화고(specialized vocational high school), 마이스터고(meister high school), 평준화(equalization area), 전기/후기(early/late round), 교육청(Office of Education).

## 확인
- `npm run validate && npm run build`
- `BASE=http://localhost:5000 node scripts/i18n-check.cjs` — 영어 모드에서 페이지별로 남은 한글 수를 센다. 목표는 0(고유명사는 data-keep-ko로 제외).
- 미리보기: 주소 뒤에 `?lang=en`. 전환 버튼은 번역이 끝나면 `LANG_PUBLIC = true`로 공개.
