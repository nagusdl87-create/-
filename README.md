# 마이로드 (MyRoad) — 중학생 진로·학업 설계 플랫폼

나를 알고(흥미·가치관·강점) → 직업을 찾고 → 학과·고교 과목으로 길을 잇고 → 고교 유형을 고르고 → 학기별로 실천·기록하는
**5단계 여정형** 진로·학업 설계 웹앱입니다. 서버·DB 없이 동작하며 데이터는 사용자 브라우저(localStorage)에만 저장됩니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Vercel 배포: 저장소를 Vercel에 연결하면 별도 설정 없이 배포됩니다(Next.js 15, 정적 페이지).

## 기능

| 단계 | 경로 | 내용 |
|---|---|---|
| 홈 | `/` | 진행률 대시보드, 다음 할 단계 안내, 추천 직업, 이번 학기 할 일 |
| 1 나 알기 | `/discover` | 홀랜드 6유형 기반 30문항 흥미 탐색, 가치관 3개, 강점 선택 → 육각형 결과 |
| 2 직업 찾기 | `/jobs`, `/jobs/[id]` | 직업 41개, 흥미+가치관 일치도 순 정렬, 분야·유형·키워드 필터, 찜하기 |
| 3 길 잇기 | `/path` | 직업 → 대학 학과 → 고교 선택과목 → 중학생 지금 할 일 흐름도, 공통 과목(Plan B), 진로 가설 문장 |
| 4 고교 고르기 | `/highschool` | 고교 유형 8종 안내, 적합 유형 퀴즈(찜한 직업 반영), 최대 3개 나란히 비교 |
| 5 계획·기록 | `/plan` | 중1~중3 학기별 할 일(기본 제공 + 직업 맞춤 추천), 과목별 공부 목표, 4단계 성찰 활동 기록 |
| 리포트 | `/report` | 한 장 요약, 인쇄/PDF, 공유 링크(URL에 데이터 인코딩, 서버 저장 없음), JSON 백업/복원 |

## 구조

```
src/
  app/            페이지 (App Router)
  components/     Nav, Radar(SVG 육각형), JobCard, PathFlow, ui
  data/           riasec.ts(문항), jobs.ts(직업), highschools.ts(고교 유형·퀴즈), plan.ts(학기·할 일)
  lib/            store.tsx(상태·저장·공유 인코딩), match.ts(점수·추천 로직)
```

## 주의

- 흥미 탐색은 표준화된 심리검사가 아닙니다. 커리어넷 등 공식 검사와 함께 쓰도록 안내합니다.
- 고교 유형 정보는 전국 공통의 일반적인 특징입니다. 실제 전형은 지역 교육청과 학교 공지를 확인해야 합니다.
- 직업 데이터는 직접 작성한 예시입니다. 실제 서비스로 쓰기 전에 커리어넷 Open API 등 공식 데이터와 연동하거나 검수하세요.
